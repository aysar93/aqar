## التحقق المحدود بعد النشر

1. تحقق metadata: الدوال الثماني ACTIVE، الهوية الجديدة للأربع فقط، وسر OneSignal غير مربوط. الإعداد push_bridge_config/rollout مطابق: mode=paused، percent=0، legacyIngressCoordinated=false، وجميع قوائم الحسابات والأجهزة وlegacy فارغة. لم تتغير قيمه.

3. سجل Cloud Run أربع طلبات أحداث ناجحة، واحدة لكل خدمة، ضمن نافذة الأحداث الاصطناعية. هذا يثبت استدعاء خدمات المحفزات واستجابتها بنجاح؛ لا يُقدّم كاختبار استلام جهاز أو إعادة تحقق كامل لمسارات المحتوى التي اختبرت سابقًا.
4. حُذفت المستندات الأربعة وتحقق غيابها. حذف المستند الداخلي قد يولد حدث written إضافيًا خاملًا؛ لا يمثل إعادة إرسال أو إعادة إنشاء اختبار.
