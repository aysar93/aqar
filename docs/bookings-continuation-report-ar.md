## حدود باقية قبل الإطلاق

- الفلاتر الحالية تطبق على السجلات المحملة من Firestore؛ لا يوجد محرك بحث مفهرس أو pagination إنتاجي شامل. فحص التوافر قد يقرأ كل سجلات الحجز/الإغلاق للمكان، ويحتاج تحديد نطاقات وفهارس وقياس تكلفة على بيانات كبيرة. أسماء المجمع والوحدات تسهل التجميع، لكنها ليست بنية منتجع ذات مخزون مشترك أو إدارة دفع جماعي.
- فحص فترة التوافر ليس محرك مطابقة أسعار وشفتات كاملًا: يجب أن يختار الزبون لاحقًا شفتًا صحيحًا أو عدد ساعات كاملًا؛ الخادم يرفض الوقت غير المطابق. نتائج البحث لا تحجز المخزون.
- لا أسعار موسمية كاملة أو عرض أسبوعي بالساعات أو no-show أو إكمال آلي أو كوبونات. هذه نواقص التقرير السابق ولم تُخفَ.
- لا تحقق قانوني آلي للملكية ولا مكافحة برمجيات ضارة للوسائط. إزالة الوسيط تحذف الملف، لكن فشل حذف Storage بعد سحب النشر يحتاج إعادة محاولة؛ ليست هناك طابور تنظيف دائم أو سياسة احتفاظ شاملة للأصول المهجورة.
- الدعم يتضمن التولي والرد والإغلاق؛ لا SLA أو تصعيد متعدد الفرق أو مرفقات أو سجل ردود متعدد لكل تذكرة. الرد الأخير محفوظ في التذكرة؛ لا بريد/رسائل للآخرين خارج إشعارات التطبيق.
- مراجعة التقييمات لها تدقيق واستجابة عامة محمية؛ لا تقييم متبادل أو استئناف أو اكتشاف احتيال آلي. المتوسط يحسب من التقييمات المنشورة عند القراءة، وليس نظام تجميع واسع النطاق.
- لا إثبات دفع مصرفي أو تكامل Qi/ZainCash رسمي. المالية والإيصالات والاستردادات والتسويات تظل مراجعة بشرية. لا تُجمع بيانات المكاتب القديمة مع مراجع دفع الحجوزات، ولا يُعد الرصيد المتبقي مالًا محصلًا.
- لا قبول iOS حقيقي، ولا تسليم إشعارات خلفية/APNs/فتح إشعار على الأجهزة، ولا ماسح كاميرا مقبول بصريًا أمام QR فعلي، ولا قبول كامل فيديو/خرائط/بنرات على شبكة هاتف مستقلة.

## staging والنسخة المستقلة

## إعادة التشغيل المحلية

من جذر المستودع:

```powershell
firebase emulators:start --only auth,functions,firestore,storage,database --project demo-aqar --config firebase.bookings-local.json
```

في نافذة أخرى، عرّف `GCLOUD_PROJECT=demo-aqar` و`FIRESTORE_EMULATOR_HOST=127.0.0.1:8185` و`FIREBASE_AUTH_EMULATOR_HOST=127.0.0.1:9099` ثم شغّل `node functions/seed_booking_emulators.js`. الـseed يرفض السحابة أو الإنتاج. حسابات customer/owner/admin/reviewer @test.invalid وكلمة المرور AqarTest123! تخص المحاكيات فقط.

مهلة HTTP في flavor المحاكيات 90 ثانية لاستيعاب بدء العمال المحلي البطيء؛ مهلة خدمات الإنتاج لم تتغير.

عبر USB: مرر ADB المنافذ 9099 و5001 و8185 و9198 إلى المنافذ نفسها. البناء `flutter build apk --debug --flavor bookingsTest --target lib/bookings_test_main.dart --target-platform android-arm64 --split-per-abi`. هذه نسخة arm64 Debug منفصلة عن تطبيق الإنتاج، وليست نسخة متجر. لا تحول أموالًا إلى الحسابات الوهمية.

اختبار الهاتف القابل للإعادة: `flutter test integration_test/bookings_device_test.dart --flavor bookingsTest -d <device-id>` بعد تشغيل المحاكيات وإضافة البيانات وتمرير المنافذ.
