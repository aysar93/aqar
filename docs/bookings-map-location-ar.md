# خريطة الحجوزات والموقع والاتجاهات

أُكملت الخريطة الموجودة دون إنشاء شاشة مكررة. تعرض الأماكن النشطة ذات الإحداثيات الصالحة والأسعار حسب عوامل البحث. العلامة تفتح ملخص المكان والشروط والاتجاهات والانتقال إلى شاشة التفاصيل والحجز الموجودة.

زر «موقعي الحالي» وحده يبدأ طلب إذن المقدمة عند الحاجة، ثم قراءة واحدة بدقة متوسطة ومهلة 15 ثانية. لا توجد كتابة لموقع المستخدم إلى Firestore أو ملفات أو تحليلات ولا اشتراك تتبع. يبقى الموقع في ذاكرة شاشة الخريطة، ويمكن إخفاؤه ويزول عند إغلاقها. الأماكن القريبة ضمن 50 كم مرتبة بمسافة خط مستقيم؛ لا تمثل مسافة القيادة. عوامل البحث تنطبق عليها.

تستمر الخريطة بعد رفض الإذن أو تعطيل GPS، مع رابط الإعدادات عند الرفض الدائم أو تعطيل الخدمة. تحتفظ الشاشة بآخر قائمة أماكن محملة إذا أخفق stream، وتعرض أخطاء خلفية الخريطة وإعادة التحميل. لا تتوفر خرائط offline كاملة أو ضمان حجز دون شبكة؛ الحجز يتطلب استجابة الخادم.

خلفية OpenStreetMap ترسل طلبات مربعات المنطقة المعروضة إلى مزود الخرائط. الاتجاهات ترسل إحداثيات المكان فقط إلى تطبيق خارجي: geo على Android وApple Maps على iOS، مع رابط Google Maps بديل إذا فشل الفتح. لا يُرسل موقع المستخدم بوصفه origin من التطبيق؛ تطبيق الخرائط الخارجي يدير أذوناته ومساره.

نموذج المالك الموجود يدعم إضافة الإحداثيات وتعديلها. أُضيف تحقق محلي للقيمتين معًا، للأرقام المحدودة ونطاق العرض ±90 والطول ±180، مع إدخال الأرقام باتجاه LTR داخل واجهة RTL. الخادم الموجود يتحقق من القيم وصلاحية المالك أيضًا. الإحداثيات اختيارية؛ المكان بلا إحداثيات صالحة يبقى قابلًا للحجز عبر القائمة ولا تظهر له علامة.

الاختبارات: booking_location_test.dart وbooking_map_test.dart، مع اختبارات عوامل البحث والواجهات وعزل staging. روابط iOS مختبرة برمجيًا فقط؛ لا يمثل ذلك اختبارًا على iPhone. تقرير الجولة وقيود تجربة الهاتف تُسلّم في outputs الخاص بالمحادثة.
