# بنرات الحجوزات

تستخدم صفحة الأماكن في الحجوزات نفس BannerSlider المستخدم في الرئيسية، دون تغيير التصميم أو القياسات أو الحواف أو التمرير التلقائي أو فتح الروابط. يمر البنر مع قائمة الأماكن ولا يظهر في تبويبات العمليات المالية والحجوزات الشخصية.

البيانات مستقلة في booking_banners، وتبقى banners للرئيسية. لا توجد ترحيل أو نسخ أو حذف للبنرات الحالية. يحتفظ كل مدخل بالعنوان والوصف والصورة ونوع الوجهة ومعرفها والتفعيل والترتيب وتاريخ الإنشاء.

الإدارة من «بنرات الحجوزات» في لوحة الإدارة أو أيقونة البنرات في إدارة الحجوزات. يستخدم المسؤول شاشة البنرات الحالية للإضافة والتعديل والحذف والتفعيل والتعطيل، ويحدد الترتيب الرقمي (الأصغر أولاً) والوجهة: عقار أو مكتب أو رابط خارجي، بما فيه روابط واتساب. تحميل الصور بنفس مسار Cloudinary الحالي.

قواعد المجموعة الجديدة تسمح بالقراءة وتمنع تعديلها إلا للمسؤول غير المحظور. أُضيف الفهرس المركب isActive/order. عند الموافقة على نشر لاحق، يجب نشر قواعد وفهرس المجموعة والانتظار حتى يصبح الفهرس جاهزاً قبل تفعيل الميزة. لم تُنشر أي قواعد أو فهارس أو بيانات إنتاج ضمن هذا التعديل. قبل ذلك تخفي شاشة العرض البنرات عند رفض القراءة أو غيابها وتحافظ على قائمة الأماكن؛ شاشة الإدارة تظهر رسالة خطأ عند رفض الوصول.

التحقق: اختبار المحاكي يفحص عمليات الإدارة، منع المستخدم والضيف والمسؤول المحظور، ترتيب البنرات وتفعيلها وروابطها واستقلال بيانات الرئيسية. اختبار Flutter يفحص نطاق الشاشات الافتراضي والحجوزات وسلامة قائمة الأماكن عند غياب البنرات أو خطأ التدفق. نجحت أيضاً اختبارات الحجوزات والدفع والتنقل (8 اختبارات). تحليل الملفات المعدلة بلا أخطاء أو تحذيرات، مع ملاحظتي إهمال Radio السابقتين. لا يوجد اختبار على جهاز فعلي أو إنشاء نسخة تطبيق لهذا التعديل.
